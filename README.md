# Koro Corgi – Corgi Mini Movies (コロ・コーギー)

Eight short, cute animated corgi films (22–28 seconds each) for your pocket. Made for Rie 🐾

- Play / pause, previous / next, start over, film list
- Play all in a loop, or repeat one film
- Gentle optional music-box sound (off by default)
- Japanese by default, 日本語 / English toggle, optional 大きい文字 / Large text
- Works offline after the first visit. No ads, no login.

Corgi art: the mascots from poco-a-poco. Vite + TypeScript PWA, deployed to the gh-pages branch by GitHub Actions.

Live: https://gutsmcd-cmd.github.io/koro-corgi/
